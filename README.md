# Divine Domain · 神域

Divine Domain is a Mindustry mod by rxna. Explore Dawn, build industrial production lines and research new units, or start a seamless survival world.

## Install on PC

1. Download the Divine Domain ZIP from the **Assets** section of the [latest release](https://github.com/k7-q/Divine-Domain/releases/latest).
2. Open **Mods → Import Mod → Import File** in Mindustry and choose the downloaded ZIP.
3. Restart the game. The mod follows the language selected in **Settings → Language** and supports English, Simplified Chinese and Traditional Chinese. Other languages use English for the mod's text.

Tested with Mindustry 160.8 on PC.

## 中文安装

神域是 rxna 制作的 Mindustry 模组。你可以探索比目露，建设工业产线，研究新的单位，也可以开一张无缝生存地图。

1. 在[最新版本](https://github.com/k7-q/Divine-Domain/releases/latest)的 **Assets** 下下载神域 ZIP。
2. 打开 Mindustry 的 **模组 → 导入模组 → 导入文件**，选择下载的 ZIP。
3. 重启游戏。模组跟随 **设置 → 语言** 中的选择，支持简体中文、繁体中文和英文，其他语言使用英文。

已在 PC 版 Mindustry 160.8 验证。
